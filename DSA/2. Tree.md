##### binary tree
for non-labeled n nodes you can generate (2*n C n)/(n+1) = catalon number
for labeled n nodes you can generate  ( (2 * n C n)/(n+1) ) * n!  = catalon number
for n node there 2^(n-1) trees with maximum height 
for h height min nodes = h+1, max nodes = (2^(h+1)) - 1

##### traversing 

- linear DS -> forward or backward
- non-linear DS 
	- Preorder -> node, left, right
	- Inorder -> left, node, right
