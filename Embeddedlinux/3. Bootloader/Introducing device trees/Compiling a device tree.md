[dtc] ---> Device Tree Compiler & it's two way compiler
[dts] ---> Device Tree Source
[dtb] ---> Device tree Binary


**$ dtc simpledts-1.dts -o simpledts-1.dtb**

->->-> The dtc does not give helpful error messages and makes no checks other than on the basic syntax of the language, which means that debugging a typing error in a source file can be a lengthy process.
