- C++ is a complied language 
- An ***executable*** program is created for a specific hardware/system combination , it is ***not portable***
- The concept ***portable*** in that manner means that the ***source code*** can be successfully compiled and run on a variety of systems 
- The ISO C++ standard defines two kinds of entities:
	- Core language features 
	- Standard library components 
-  C++ is a statically typed language -> the type of every entry (object , value , name,expression) must be known to the compiler at its point of use.
-  int is the program's return value to the system , If no value returned the system will receive a value indicating successful compilation , A non-zero value indicates failure. 
 ```
 int main () {}  // the minimal c++ program
```
