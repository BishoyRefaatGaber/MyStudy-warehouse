
### ```int inch;``` -> type, object, value, variable 
- ***Declaration*** : is a statement that introduce an entity into the program. It specifies a type for the entity : 
	- A ***type*** defines a ***set of possible values*** and a ***set of operations***. 
	- An ***object*** is ***some memory*** that holds a value of some type.
	- A ***value*** is a ***set of bits*** interpreted according to a type.
	- A ***variable*** is a ***named object***.
