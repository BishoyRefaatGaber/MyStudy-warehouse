
- ***Logical address*** -> generated by the CPU , also known as virtual address
- ***Physical address*** -> address seen by the memory unit

**** Logical and physical address are the ==same== in ==compile-time== and ==load-time== address-binding schemes;  logical ( virtual ) and physical addresses ==differ== in ==execution-time== address-binding 

---

> Memory-Management Unit ( MMU )

- Hardware device that maps logical ( virtual ) to physical address
- Physical add = relocation reg + user process add
 **** The user program deals with logical address it never sees the real physical address
