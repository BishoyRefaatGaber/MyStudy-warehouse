
- CPU utilization -> must be busy
- Throughput -> work per unit time
- Turnaround time -> execution time from response to termination
- Waiting time -> time waiting in the ready queue
- Response time  -> time from response to the first response 

---

> ***Optimization Criteria***

- **Maximum**
	- CPU utilization
	- Throughput
- **Minimize**
	- Turnaround time
	- Waiting time
	- Response time
- **Considerations**
	- Minimize maximum response time 
	- Minimize the variance of response times
