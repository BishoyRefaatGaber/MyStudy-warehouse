

![[Traditional Computing.jpg]]

-  Single processor systems
-  Multiprocessor systems -> parallel system or tightly-coupled systems
	- increase throughput
	- economy of scale 
	- increase reliability 
		- Graceful degradation
		- Fault tolerant system
-  Multicore systems -> every multicore is multiprocessor but not the opposite
-  Clustered systems -> loosely-coupled systems

---

> ***types of multiprocessing**

- Asymmetric multiprocessing
- Symmetric multiprocessing

---

> ***Types of clustering**

-  Asymmetric clustering -> ***high-availability service*** 
	- one node is in hot-standby mode
-  Symmetric clustering -> ***high performance computing***

***Parallelization**  -> divides a program into separate components to run in parallel
