> Distributed computing

- Distributed system -> collection of physically separated computer systems that are networked together to solve single large problems 
  - May take the form of  ***client-server computing*** or ***peer-to-peer***
  - Connected by :
	  - PAN -> Personal-area networking (wireless link over a short distance)
	  - LAN -> Local-area networking (room , building , campus)
	  - MAN -> Metropolitan-area networking (city)
	  - WAN -> Wide-area networking (cities , countries)


> Cloud Computing

- Delivers computing as a services and users pay based on usage
- Uses virtualization to run millions of VMS on servers
- Categorized as :
	- Public cloud -> available to any one via internet
	- Private cloud -> used only by a company
	- Hybrid cloud -> mix between both
- It may provide :
	- software as a service (SaaS) -> application (google docs)
	- Platform as a service (Paas)-> software stack (google firebase)
	- Infrastructure as a service (Iaas) -> servers or storage over the internet
