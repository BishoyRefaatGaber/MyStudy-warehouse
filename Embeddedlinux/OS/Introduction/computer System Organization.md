> ***Caching**

- Caches -> installed to improve access time or transfer rate .
- Caching -> the use of high-speed memory to hold a copy of recently-accessed assuming that it will be needed again .
- [Cash coherency] -> ensures that an update to some data in a cache is reflected immediately in other caches containing a copy of that data .
