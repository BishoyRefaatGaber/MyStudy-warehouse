## SW characteristics
##### Operational
-  Correctness -> meet customer requirements
- usability -> easy to use
- efficiency -> low time and space complexity
- security -> hardware and software
- safety 

##### transitional
- interoperability -> ability to exchange information with other applications
- reusability 
- portability

##### Maintainable
- flexibility -> easy to change SW 
- extensibility -> easy to add features
- scalability -> can handle high amount of users and workloads
- testability
- modularity

## SDLC
##### waterfall 
- requirement -> analysis -> design -> coding -> testing -> acceptance
- cons

##### V-model
