##### Vsphere features
- Host-based firewall
- Memory hardening  --> provides protection against malicious code to use memory **exploits** to take advantage of vulnerabilities.
- Kernel module integrity --> Digital signing ensures the integrity and authenticity of modules, drivers and applications as they are loaded by the VMkernel.
- Trusted Platform Module (TPM 2.0) --> secure cryptoprocessors that enhance host security by providing a trust assurance rooted in hardware
- UEFI secure boot
- Encrypted core(crash) dumps --> a memory snapshot of a running process. If host crashes
- Small disk footprint
- Quick boot for faster patching and upgrades
- Installable on hard disks, SAN LUNs, SSD, SATADOM, and diskless hosts
