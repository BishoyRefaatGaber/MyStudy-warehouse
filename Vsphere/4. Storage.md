## Concepts

###### Datastore 
-  logical storage unit that can use space on one or more physical storage devices.
-  used to hold data such
	- VMs
	- VM templates
	- ISO images
-  types : 
	-  VMFS
	- NFS
	- vSAN
	- vSphere Virtual Volumes
-  Access methods
	-  Block-backed storage
		- Storage Area Networks (SANs)  through either iSCSI or Fibre Channel
		- VMFS
		- vSAN
		- vSphere Virtual Volumes datastores
	-  File-backed storage
		- network-attached storage (NAS)
		- NFS
		- vSphere Virtual Volumes datastores
-  Content
	- Files 
		- NAS
	- Objects
		- SAN


###### Storage


Raw Device Mapping -->  not a datastore, raw device mapping (RDM) gives a VM direct access to a physical LUN.
The mapping file (-rdm.vmdk) that points a VM to a LUN must be stored on a VMFS datastore.

- Storage Device Naming Conventions
	- Runtime name: Uses the vmhbaN:C:T:L convention. This name is not persistent through reboots.
	- Target: Identifies the target address and port.
	- LUN: A unique identifier designated to individual or collections of storage devices.
